# Report: Dependency- & Build-Hygiene-Analyse (Studyplanner)

Geprüfte Datei: `pom.xml` (Single-Module-Projekt, kein Multi-Module-Build, kein separates BOM). Ergänzend versucht: `mvn dependency:tree` / `mvn dependency:analyze` — in dieser Sandbox nicht ausführbar (TLS-Zertifikatsfehler beim Zugriff auf Maven Central, `PKIX path building failed`). Die untenstehenden Befunde basieren daher auf manueller Analyse von `pom.xml` + Quellcode-Grep (Import-Suche nach tatsächlicher Nutzung) + Web-Recherche zu aktuellen Versionen/CVEs (Stand: Juli 2026). **Für eine abschliessende, automatisierte Bestätigung sollten `mvn dependency:analyze`, `mvn versions:display-dependency-updates` und ein OWASP-Dependency-Check-Lauf lokal (mit funktionierendem Netzwerkzugriff) nachgeholt werden.**

## Priorisierte Massnahmen (Top 5)

1. **Spring Boot Parent-Version anheben** (`pom.xml:11`, aktuell `3.4.4`) — schliesst mehrere dokumentierte CVEs (bis CVSS 9.1). Angesichts der Abgabefrist (10.07.2026) minimal auf **3.4.16** (Patch innerhalb der aktuellen Minor-Linie, geringes Breaking-Change-Risiko) heben; ein Wechsel auf 4.0/4.1 danach nachziehen. **Kritischster Einzelfund im gesamten Report.**
2. **Ungenutzte Dependencies bereinigen**: `guava`, `jmolecules-ddd`, `jmolecules-archunit`, `archunit-junit5`, `equalsverifier` — entweder entfernen oder (empfohlen für die beiden ArchUnit-Artefakte) tatsächlich zur automatisierten Absicherung der Schichtenarchitektur nutzen, die in einem früheren Review manuell geprüft wurde.
3. **Maven Wrapper ergänzen** (`mvnw`, `mvnw.cmd`, `.mvn/wrapper/`) — sichert reproduzierbare Builds unabhängig von der lokal installierten Maven-Version, insbesondere wichtig, da laut Aufgabenstellung alle Gruppenmitglieder aktiv am Repository arbeiten sollen.
4. **CVE-Scanning einmalig vor Abgabe durchführen**: `mvn dependency:analyze` (used/unused, used-undeclared) und `mvn versions:display-dependency-updates`, idealerweise ergänzt durch OWASP Dependency-Check — in dieser Sandbox wegen TLS-Problemen nicht ausführbar, sollte aber vom Team lokal nachgeholt werden.
5. **Kleinere Versions-Drifts nachziehen**, falls die jeweilige Dependency doch beibehalten wird: `archunit-junit5` → `1.4.2`, `equalsverifier` → `4.5`, `guava` → `33.6.0-jre`.
